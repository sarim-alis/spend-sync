# Expense Tracker App 💰

A full-stack Expense Tracker built with the MERN stack, designed to evolve into a production-ready SaaS and mobile app (Play Store ready).

---

## 🚀 Features

### 📸 Core Features
- OCR receipt scanning
- Monthly analytics
- Budget alerts
- Shared wallets
- Recurring expenses
- Charts & visual insights
- Export data to CSV/PDF

---

## 🧩 Phase 1 – MVP

- User authentication (JWT)
- Add / Edit / Delete transactions
- Categories (Food, Transport, Bills, etc.)
- Income vs Expense tracking
- Monthly summary dashboard
- Charts for visualization
- Search & filtering transactions

---

## ⚙️ Phase 2 – Production Features

- Recurring transactions automation
- Budget goals & limits
- Savings goals tracking
- Receipt image upload (AWS S3)
- Export reports (PDF / CSV)
- Multi-currency support
- Dark mode UI
- Push notifications for bill reminders

---

## 🧠 Phase 3 – Advanced Features

- Shared wallets (family & friends)
- OCR receipt scanning
- AI-powered spending insights  
  - “You spent 30% more on food this month.”
- Monthly expense prediction
- Offline support with sync
- Real-time updates across devices

---

## 📱 Vision

This project is designed to grow into a **cross-platform financial management app** with:
- Web dashboard
- Mobile app (Android/iOS)
- SaaS monetization potential

---

## 📌 Future Improvements
