# 💸 Spend Sync

Spend Sync is a modern expense tracker web app built with **Next.js** that helps you manage your finances easily. Track your income, expenses, and savings in one clean dashboard.

---

## ✨ Features

- ➕ Add income, expenses, and savings
- 📊 Track overall balance in real-time
- 📅 Monthly financial overview
- 🧾 Category-wise expense tracking
- 🔍 Simple and clean UI
- ⚡ Fast performance with Next.js

---

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run development server
```bash
npm run dev
```

### 3. Open in browser
http://localhost:3000
